Transmog Colour Boundaries

Each row runs from one colour to its neighbour, using items you captured in the Transmogrifier. The label under every tile says which colour it is filed as right now, and the gold marker shows where the row switches. It starts where crowd-sourced colour naming would switch. Click the first item that looks like the second colour: it and everything after it get the second colour, everything before it keeps the first. The thin bar above each label is the colour the addon measured for that item.

If an item fits neither colour, or the addon measured the wrong part of it, mark it with ✕ in its corner. If a row has no clean split, tick that box and say why in the note.
